# TOEIC Preparation — Luyện thi TOEIC

## Format hiện hành (không đổi từ 2018)

### Listening & Reading (600 điểm)
- **Phần 1–4: Listening** (khoảng 45 phút, 100 câu)
  - Part 1: Photographs (6 câu)
  - Part 2: Question-Response (25 câu)
  - Part 3: Conversations (13 câu, 3 câu/conversation)
  - Part 4: Short Talks (10 câu, 3 câu/talk)
- **Phần 5–7: Reading** (khoảng 75 phút, 100 câu)
  - Part 5: Incomplete Sentences (30 câu)
  - Part 6: Text Completion (4 bài × 4 câu = 16 câu)
  - Part 7: Reading Comprehension (54 câu: single + double passages)

### Speaking & Writing (400 điểm)
- **Speaking** (11 câu, ~20 phút): Read aloud, Repeat sentence, Describe picture, Respond to questions, Suggest solutions, Express opinion
- **Writing** (8 câu, ~60 phút): Write a sentence (5 câu), Respond to written requests (2 câu), Write an opinion essay (1 câu)

## Ghi chú
- Folder chứa tài liệu JIM (Listening/Reading) và Test 1/2/3
- Khuyến nghị: bổ sung nguồn chính thức từ ETS: https://www.ets.org/toeic.html
- TOEIC S&W là bài thi riêng — nên luyện tập độc lập với L&R

## Cập nhật format
ETS **không thay đổi format** TOEIC L&R từ 2018 đến 2026. Các tài liệu trong folder vẫn đúng format cơ bản.
